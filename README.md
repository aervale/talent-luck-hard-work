# Hard work, luck, and talent

An interactive site showing how people split the credit for their own success between **hard work**, **luck**, and **talent**.

- 280 answers: 175 from an anonymous form sent to MIT dorm lists (Oct 2026) and 105 asked in person.
- Views: triangle (ternary) scatter, 3D scatter, 3D weight map, and a density view from above.
- Two-panel mode compares any two groups (e.g. MIT vs not MIT), each with its own settings.
- Filters by year, region, major, and background (athlete, build team, olympiad, music, birth order).
- "Save JPG" exports a print-style chart with median, mean, and a color key.

No names are included in the data. Answers that did not total 100% were rescaled; two-number answers were read as hard work and luck.

Open `index.html` in a browser, or view it with GitHub Pages.
